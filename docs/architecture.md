# 架构设计

## 整体架构

```
┌─────────────────────────────────────────┐
│           PyQt6 主窗口 (FruitApp)       │
├─────────┬───────────┬─────────────────┤
│ 摄像头   │  识别引擎  │   UI 组件        │
│ Camera  │  Fruit    │  - 毛玻璃面板    │
│ Thread  │  Model    │  - 主题切换      │
│ (30fps) │  (PyTorch)│  - 结果展示      │
└─────────┴───────────┴─────────────────┘
```

## 模块说明

### 1. CameraThread
- 继承 QThread，独立线程读取摄像头
- 30fps 采集 BGR 帧
- 通过 pyqtSignal 发射帧到主线程

### 2. FruitModel
- 加载 MobileNetV2 预训练权重
- 输入: 224x224 RGB 图像
- 预处理: Resize(256) -> CenterCrop(224) -> Normalize
- 输出: Top-5 预测类别及置信度

### 3. FruitApp
- 无边框毛玻璃窗口
- 支持拖拽移动
- 深色/浅色主题切换
- 结果实时显示

## 技术选型

| 组件 | 选择 | 原因 |
|------|------|------|
| 模型 | MobileNetV2 | 轻量(14MB)、快速、准确率高 |
| UI | PyQt6 | 原生窗口、毛玻璃、跨平台 |
| 摄像头 | OpenCV | 简单稳定、跨平台 |
| 推理 | PyTorch | 直接加载 .pt，无需 ONNX |
